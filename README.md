# Pink Tablet — Friday Beer Bot

Telegram-бот выбирает одного участника группового чата каждую пятницу в 15:00 по времени `TIMEZONE` и публикует победителя. Приз: одно пиво на любом турнире Pink Tablet.

## Как это работает
- Бот записывает пользователей, которые отправляют сообщения в группе после добавления бота.
- Боты не участвуют.
- Каждую пятницу в 15:00 бот случайно выбирает одного пользователя в каждом чате, где есть участники.
- Победитель сохраняется в базе, чтобы при повторной обработке не объявить второго победителя за ту же дату.
- Команды: `/start`, `/beer_help`, `/beer_status`.

## Настройка Telegram
1. Создайте бота через [@BotFather](https://t.me/BotFather) командой `/newbot`.
2. Скопируйте токен.
3. В BotFather выполните `/setprivacy` → выберите своего бота → `Disable`. Это нужно, чтобы бот видел обычные сообщения группы и мог учитывать участников.
4. Добавьте бота в нужный групповой чат.
5. Участникам нужно написать хотя бы одно сообщение после добавления бота. Бот не может задним числом собрать список всех участников чата.

## Деплой на GitHub + Railway
1. Загрузите содержимое проекта в новый GitHub-репозиторий.
2. В Railway создайте проект `Deploy from GitHub Repo` и выберите этот репозиторий.
3. В Variables добавьте:
   - `BOT_TOKEN` — токен от BotFather
   - `TIMEZONE` — `Europe/Moscow` (или нужная зона IANA)
   - `DB_PATH` — `/data/bot.db`
4. Добавьте Railway Volume и подключите его к сервису по пути `/data`. Это важно: без постоянного диска список участников и история победителей могут потеряться при новом деплое/перезапуске.
5. Убедитесь, что сервис запущен как worker по `Procfile` (`worker: python bot.py`).

## Важные ограничения
- Один сервис/одна копия бота должна работать одновременно: несколько реплик могут проводить дублирующиеся розыгрыши.
- В розыгрыш попадают только люди, чьи сообщения бот увидел после добавления в чат и отключения Privacy Mode.
- Telegram может не доставлять боту все события в некоторых условиях; для надёжного сбора участников попросите всех написать `/start` в личку боту и сообщение в группе.
- Если Railway-сервис был выключен в момент розыгрыша, бот проведёт розыгрыш при следующем запланированном времени, а не задним числом.
- Розыгрыш и выдача алкогольного приза — только для совершеннолетних и при соблюдении законодательства и правил площадки. Организатор должен проверить возраст победителя; если он не может законно получить алкоголь, не выдавайте алкогольный приз.

## Локальный запуск
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="токен"
python bot.py
```
