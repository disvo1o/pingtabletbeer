# Pink Tablet — Friday Beer Bot

Бот выбирает одного участника группового чата каждую пятницу в 15:00 по времени `TIMEZONE` и объявляет победителя, которому полагается одно пиво на любом турнире Pink Tablet.

## Функции
- Запоминает пользователей, отправляющих сообщения в группе после добавления бота.
- Не учитывает ботов.
- Каждый пятничный розыгрыш выбирает одного случайного участника.
- Сохраняет участников и результаты в SQLite.
- При упоминании бота (`@username`) в вопросе о пиве отвечает одной из 50 случайных шуточных фраз.
- На вопрос «я выиграл пиво?» проверяет сохранённые результаты и выбирает из 50 фраз для случая без выигрыша.
- Команды: `/start`, `/beer_help`, `/beer_status`.

## Настройка Telegram
1. Создайте бота через @BotFather командой `/newbot`.
2. Скопируйте токен.
3. Выполните в BotFather `/setprivacy` → выберите бота → `Disable`, чтобы он видел обычные сообщения группы.
4. Добавьте бота в нужный чат. Пользователи попадут в список после сообщения, отправленного после добавления бота.

## GitHub + Railway
1. Загрузите файлы проекта в GitHub.
2. В Railway выберите Deploy from GitHub Repo.
3. Добавьте Variables:
   - `BOT_TOKEN` — токен BotFather
   - `TIMEZONE` — `Europe/Moscow`
   - `DB_PATH` — `/data/bot.db`
4. Добавьте Railway Volume и подключите его к `/data`, иначе база может потеряться после пересоздания контейнера.
5. Запускайте только один экземпляр сервиса, чтобы не было повторных розыгрышей.

`runtime.txt` задаёт Python 3.12.11. Если Railway/Mise снова выдаёт ошибку GitHub attestation, можно добавить Variable `MISE_PYTHON_GITHUB_ATTESTATIONS=false`.

Приз предназначен только для совершеннолетних; организатор должен соблюдать местное законодательство и правила площадки.
